# Portal Institucional — JAC Vereda Santa Bárbara

## Incluye
- Página institucional responsive.
- Inicio y presentación de la Junta.
- Directivos.
- Noticias y comunicados.
- Agenda comunitaria.
- Repositorio de documentos.
- Sección de afiliados y carnets.
- Manual de identidad visual.
- Formulario PQRS con radicado local de demostración.
- Persistencia local del formulario mediante `localStorage`.
- Identidad visual basada en el logo suministrado.

## Puesta en producción
Esta versión es un front-end funcional. Para producción se recomienda conectar:
1. Base de datos.
2. Panel administrativo con autenticación.
3. Gestión de noticias, documentos y eventos.
4. Servicio de correo para PQRS.
5. HTTPS y controles de seguridad.
6. Política de tratamiento de datos personales y consentimiento.
7. Copias de seguridad y auditoría.
